# 📘 Assignment: Web Development Basics

## 🎯 Objective

Create a personal portfolio website using HTML, CSS, and JavaScript to showcase your projects and skills as a developer.

## 📝 Tasks

### 🛠️ Build HTML Structure

#### Description
Create the basic HTML structure for a portfolio website with semantic elements.

#### Requirements
Completed website should:

- Include proper HTML5 document structure with doctype, head, and body
- Use semantic HTML elements (header, nav, main, section, footer)
- Create sections for about, projects, and contact information
- Include proper meta tags and page title

### 🛠️ Style with CSS

#### Description
Add CSS styling to make the portfolio visually appealing and responsive.

#### Requirements
Completed styles should:

- Use external CSS file linked to HTML
- Apply consistent color scheme and typography
- Create responsive layout that works on different screen sizes
- Style navigation menu and interactive elements
- Include hover effects and smooth transitions

### 🛠️ Add JavaScript Interactivity

#### Description
Implement JavaScript to add dynamic functionality to the portfolio.

#### Requirements
Completed JavaScript should:

- Create external JavaScript file linked to HTML
- Add interactive navigation (smooth scrolling to sections)
- Implement a simple contact form with validation
- Create a dynamic project showcase with filtering
- Include basic animations or interactive elements

### 🛠️ Deploy and Test

#### Description
Test the website functionality and prepare it for deployment.

#### Requirements
Completed project should:

- Test all links and interactive elements work correctly
- Ensure responsive design works on mobile and desktop
- Validate HTML and CSS for proper syntax
- Include comments explaining complex code sections
- Create a README file explaining how to view the website
